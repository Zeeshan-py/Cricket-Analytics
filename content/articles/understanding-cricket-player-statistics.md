Cricket player statistics can look simple at first: runs, wickets, matches, averages. But the value of a player is rarely captured by one number.

Good analysis starts with the player's role.

## Batting statistics

The core batting numbers are:

| Statistic | What it describes |
| --- | --- |
| Runs | Total scoring output |
| Balls faced | Scoring opportunity |
| Average | Runs per dismissal |
| Strike rate | Runs per 100 balls |
| High score | Best single innings |

Batting numbers should be compared by format and batting position. A top-order Test batter and a T20 finisher are solving different problems.

## Bowling statistics

The core bowling numbers are:

| Statistic | What it describes |
| --- | --- |
| Wickets | Dismissals credited to the bowler |
| Runs conceded | Scoring allowed |
| Balls bowled | Workload |
| Economy | Runs conceded per over |
| Bowling average | Runs conceded per wicket |

For bowlers, role is vital. New-ball bowlers, middle-over spinners, and death-over specialists operate in different match conditions.

## Fielding and awards

Fielding data adds another layer: catches, stumpings, run outs, and player-of-match awards can help explain match impact.

These numbers should support the analysis, not replace it.

## Use the right comparison

When comparing players, avoid mixing roles too freely. Compare batters with similar batting roles and bowlers with similar responsibilities.

Start with the [player explorer](/players), then use [analytics](/analytics) to filter by team, format, year, or tournament where data is available.

## Summary

Player statistics are most useful when they are read as a group. Runs, wickets, averages, strike rates, economy, and match context all work together to describe performance.
